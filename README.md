# FinInsight — Expense Control and Profitability Analytics

## Project Overview

FinInsight is a Data Analytics internship project focused on financial expense monitoring, budget variance analysis, departmental and regional performance, and forecast comparisons.

The project uses the Microsoft Contoso Financial Sample Dataset to develop an interactive Power BI report supported by PostgreSQL and SQL analysis.

## Tools & Technologies

- Microsoft Excel
- Power Query
- PostgreSQL and SQL
- Power BI
- DAX

## Dataset

The dataset contains three related tables:

| Table | Records |
|---|---:|
| FactFinanceData | 541,522 |
| DimAccounts | 641 |
| DimExecGeography | 2,036 |

**Selected analysis period:** July–December 2012.

## Key Financial Results

| Metric | Value |
|---|---:|
| Actual Expenses | $626.72M |
| Expense Budget | $744.93M |
| Expense Variance | −$118.21M |
| Budget Utilization | 84.13% |

## Key Insights

- Payroll was the largest expense category, with an actual balance of $411.99M.
- Outsourced Resources recorded $176.67M.
- Other People exceeded its budget by $3.60M.
- Product Development exceeded its budget by $1.52M.
- Forecast comparisons revealed differences in actual and forecast record coverage.

## Project Deliverables

- Interactive Power BI dashboard
- SQL analysis scripts
- Financial analysis report
- PowerPoint presentation
- Exported SQL results

## Limitations

The project uses a historical financial sample dataset. Signed expense allocations affect the interpretation of variances, and forecast scenario comparisons should not be treated as verified forecast accuracy measurements.
